# Aditya Gola — Portfolio

Personal portfolio website built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy on Vercel

1. Push this project to your GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Framework preset: **Vite**. Build command: `npm run build`. Output directory: `dist`.
4. Deploy.

The résumé is included at `public/resume.pdf`, so the Résumé button works automatically after deployment.

## Project links

Project links are maintained in `src/constants/portfolio-data.ts`. The current public GitHub repositories are linked directly there.
